# Java DevOps Application

A Java Maven application built and packaged using Docker.

## Technologies
- Java 21
- Maven
- Docker
- Jenkins
- SonarQube
- Kubernetes
- Helm
- Argo CD

## Application
The application runs on port `8080`.

## CI/CD Pipeline
GitHub → Jenkins → Maven Build & Test → SonarQube → Docker Build & Push → Helm → Argo CD → Kubernetes

`daddykavin/java-devops-app`
